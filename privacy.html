Privacy Policy

Last updated: 20 November 2026

Channel Uploader is a private tool used only by the owner of the YouTube channels listed on the home page. It is not offered to other people.

What data it uses

With the owner's permission, the tool uses the YouTube Data API to upload videos, set thumbnails, titles, descriptions, tags and publish times, and manage playlists on the owner's own channels. It reads basic channel information (channel name and ID) to confirm it is working on the right channel.

How data is stored

The Google sign-in token is stored only on the owner's own computer. No data is sent to any server other than Google's. Nothing is sold, shared or used for advertising.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The tool also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Contact the owner through the About page of either channel above.
